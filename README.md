## Milestones & Deliverables
- **Stage 0** (`v0.1-stage0`): Bootloader, 32-bit Protected Mode, VGA, Keyboard, Shell

- **Stage 2** (`v0.3-stage2`): Kernel Threads, Mutex Locks, Counting Semaphores, Sync Demos
- **Stage 3** (`v0.4-stage3`): Physical Memory Manager (PMM), 4 KB Frame Bitmap Allocator
- **Stage 4** (`v0.5-stage4`): 1 MB RAM Disk, Superblock, Inodes, File Operations (`ls`, `touch`, `cat`, `write`, `rm`, `fstest`)
